# Roadmap

## Vision

Bachkatov Portfolio is intended to evolve alongside my professional career.

Rather than remaining a static portfolio, the project will progressively become a central platform for showcasing software engineering projects, cybersecurity research and technical writing.

Each version introduces meaningful improvements while preserving the existing architecture and design philosophy.

---

# Version 1.0 — Foundation

## Objective

### Features

- Django architecture
- Component-based templates
- Layered CSS architecture
- Context Processors

- Production deployment
